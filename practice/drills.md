# 15 Drills — 10 Min Each (do in order)

1. Lines: graph `y=2x+1, y=-x+4, y=0.5x-2` in <45s total.
2. Sliders: `y=mx+2` add m slider, drag -3..3, describe steepness.
3. Systems easy: solve 3 textbook 2x2 via intersection, verify by plug.
4. Systems word: write `y=50+25x` + `y=20+30x` → find break-even x.
5. Quadratics roots: graph 5 `ax²+bx+c`, list roots without factoring.
6. Vertex: 5 quadratics, list (h,k) + max/min. Check -b/2a.
7. Zero method: `x²-3x-4=0`, `2x²-8=0` via LHS-RHS zeros.
8. Equivalents: plug x=2 for 10 choices, then graph survivor.
9. Tables: table-test 5 “which value” Qs from QBank Easy.
10. Inequalities: graph 5 `y>mx+b`, test (0,0) each.
11. Circles: type 5 equations, list center/r. Square grid on.
12. Stats: mean/median 5 sets, remove outlier, note shift.
13. Exponents: graph `2^x` vs `x^2` vs `3x`, find intersections.
14. Mixed timed: 10Q (QBank Medium) — log graph vs hand per Q.
15. Self-test: redo Drills 3+5+10 timed. Pass = ≤30s avg graphable, 90%+ correct.

Log all in `templates/desmos-log.csv`. Fail drill → repeat next day, not same day.
