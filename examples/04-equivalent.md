# Example 04 — Equivalent (plug x=2)

**Q:** Which is equivalent to `(x+3)(x-2)`? A) `x²+x-6` B) `x²-x+6` C) `x²+5x-6` D) `x²-5x-6`
**Desmos/table:** Plug x=2: Q =5×0=0. A:4+2-6=0 ✓. B:4-2+6=8 ✗. Test x=0: Q=-6, A=-6 ✓ → **A**.
**Graph check:** `y=(x+3)(x-2)` vs `y=x^2+x-6` overlap fully.
**Trap:** sign on -6. Plugging avoids expansion error.
