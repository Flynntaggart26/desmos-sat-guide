# Example 09 — Table-Test Choices

**Q:** Which x satisfies `3x - 5 = 10`? (easy demo of method for hard Qs)
**Desmos:** `+` → Table → x: enter A-D values → y1=3x-5 column → find 10. For hard Qs same method tests 4 complex choices without solving.
**When to use:** “which value” + messy algebra. Not for this easy one (hand 5s).
