# Example 01 — System (intersection in 20s)

**SAT-style Q:** If `2x + y = 7` and `x - y = -1`, what is `x`?
A) 1 B) 2 C) 3 D) 4

**Desmos:**
1. Type `y1=-2x+7` (solved first for y).
2. Type `y2=x+1`.
3. Click intersection → (2,3) → x=2 → **B**.

**Verify:** plug (2,3): 4+3=7 ✓, 2-3=-1 ✓.
**Trap:** they ask for x, not y. Circle x only.
**Hand alternative:** add equations → 3x=6 → x=2 (15s if seen, else Desmos wins).
