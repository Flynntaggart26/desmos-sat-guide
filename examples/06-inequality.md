# Example 06 — Inequality (shade + test)

**Q:** Which point satisfies `y > 2x + 1`? A) (0,0) B) (0,2) C) (1,1) D) (-1,0)
**Desmos:** Type `y>2x+1` → shade above line. Test (0,0): 0>1 false → not shaded. (0,2): 2>1 true → **B**.
**Trap:** boundary line included? `>` = dashed (not included), `≥` = solid.
