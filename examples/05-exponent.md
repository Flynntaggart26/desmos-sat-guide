# Example 05 — Exponent (see growth)

**Q:** For x>0, when is `2^x > x²`? (concept check)
**Desmos:** `y1=2^x`, `y2=x^2` → intersect at x=2 and x=4 → 2^x wins between? Test x=3: 8<9, so x² wins 2-4, 2^x wins after 4. Read off graph.
**Takeaway:** graph beats memorizing. Use for “which grows faster” Qs.
