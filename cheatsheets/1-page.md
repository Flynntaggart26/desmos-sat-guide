# Desmos 1-Page Cheatsheet (print this) — v2

```
LINES/SYSTEMS
y=mx+b (sliders m/b) | y1=.. y2=.. → click intersection = solution
Parallel = same m (0 solutions). Overlap fully = infinite.
TIP: write both as y=… first; circle the ask (x? y? 2x?).

QUADRATICS
y=ax^2+bx+c → roots=x-intercepts, vertex=max/min (read x AND y)
Vertex form a(x-h)^2+k → vertex (h,k). Zero method: graph LHS-RHS → zeros=solutions.
TIP: value asked = y. Touch-once = one double root. x²=k keeps ±.

EQUIVALENTS / TABLE
Plug x=2 into Q + each choice (never 0/1) → survivors → graph overlap check.
+ → Table → enter A-D x → match y. No solving needed.
TIP: (a−b)²=a²−2ab+b². Distribute to EVERY term.

INEQUALITY/CIRCLE
y>mx+b shade → test (0,0). >/< dashed (excluded), ≥/≤ solid (included).
(x-h)^2+(y-k)^2=r^2 → center (h,k) r=√(number). Flip signs!
TIP: failed test point = wrong side. Square grid on for circles.

STATS / STRATEGY
mean([...]) median([...]) → outlier pulls mean, not median.
60-SEC RULE: algebra >60s → graph. One-step → hand. Plug-back every answer.
```
