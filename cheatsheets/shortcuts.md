# Shortcuts & Typing

- `^` power: `x^2`. `_` subscript if needed (rare).
- Fractions: `(2x+3)/4` — parentheses mandatory.
- `sqrt(` or `√` button for roots. `abs(` for absolute.
- Click expression → colored dot toggles visibility (compare 2 graphs).
- Table: `+` → Table → click cell to edit, add row with Enter.
- Intersection: hover crossing → black dot + coordinates. Click to label.
- Undo: Ctrl+Z. Duplicate: hold Alt + drag (web).
- Settings (wrench): square grid for circles/geometry, radians vs degrees (SAT = degrees).

Slow typing? Practice 5 min: type 10 expressions from `examples/` without mouse. Bluebook keyboard same layout.
