05

Guide — 7-day speed plan

📅 Days 1–2 · Lines + systems

Graph 3 lines in 45s. Intersection = 2×2 solution. Sliders for word problems. Drill: 3 textbook systems, plug-verify each.

📈 Days 3–4 · Quadratics + tables

Roots = intercepts, vertex = peak. Zero-method for any equation. Table-test A–D without solving. Plug x=2 for equivalents.

🎯 Days 5–7 · Mixed + test day

Inequalities + circles (square grid). Mixed 10Q timed, log graph-vs-hand. Test day: update Bluebook, charger, slow first 10 Qs.
