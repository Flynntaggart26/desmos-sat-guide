# Contributing

1. Fork → branch (`add/trick-systems`) → PR.
2. New trick needs: title, exact Desmos input, SAT use case, when hand is faster, 1 worked example in `examples/`.
3. No copyrighted SAT Qs verbatim — write SAT-style originals.
4. Small PRs merge fastest. Test inputs at desmos.com/calculator before submitting.
