# Stats, Geometry & Inequalities

## Tables + Mean/Median
`+` → Table for data Qs. Type values, then `mean([..])`, `median([..])` to verify. Median resists outliers — check by removing max and re-running.

## Scatter + Line Fit
Plot points via table (x,y), add `y=mx+b` slider to fit roughly. Don’t overfit — SAT wants trend + outlier, not exact regression.

## Inequalities
Type `y>2x+1` → shaded side appears. Test (0,0): if true and (0,0) shaded, correct. Flip if not. For systems, shade both — overlap = solution.

## Circles
`(x-h)^2+(y-k)^2=r^2` — type to verify center (h,k), radius r (note: equation shows r²). Example: `(x-2)^2+(y+1)^2=9` → center (2,-1), r=3. Zoom square grid or circle looks oval.

## Triangles/Trig Sketch
Desmos geometry limited in Bluebook — sketch on paper, use Desmos to check coordinates/lengths only. Plug triples to verify right triangles.

Trap: radius vs r², degrees vs complementary trig. Always plug-back.
