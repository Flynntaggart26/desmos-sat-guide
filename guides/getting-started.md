# Getting Started — Bluebook Desmos vs Web

## Open Both
- Practice: https://www.desmos.com/calculator (full features, sliders, tables).
- Real: Bluebook → Math section → calculator icon (test mode, no web, same graphing).

They match for lines, quadratics, tables, intersections — everything in this repo. Test-mode differences: no saved graphs, no internet, simplified keyboard.

## 3-Minute Setup Test
1. Type `y=2x+3` → line appears. Add slider when prompted for `m` in `y=mx+2` (drag to feel slope).
2. Add `y=-x+5` → click intersection black dot → coordinates = system solution. Verify by plugging into both.
3. Press `+` → Table → enter x 0,1,2 → see y values. This tests multiple-choice without solving.

If you can do those 3 in <60s, skip to `algebra-systems.md`. Else do Drills 1-2 in `practice/drills.md`.

## Test-Day Checklist
- [ ] Bluebook updated (night before), calculator icon tested (1 graph).
- [ ] Charged laptop + charger, scratch paper + pencil (for setup, not full solve).
- [ ] Know: click intersection, add table, zoom, square grid in settings.
- [ ] Rule: graph if >60s algebra, hand if <20s (e.g. `2x+4=10`).
