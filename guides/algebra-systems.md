# Algebra & Systems with Desmos

## Lines in 15 Seconds
Type `y=mx+b` (e.g. `y=2x+3`). Add sliders for m/b once, drag to learn: m = steepness, b = y-intercept. Parallel = same m. Perpendicular SAT rarely tests — skip unless 1500+.

## Systems = Intersection (20s, 4 Qs/test)
Given:
```
2x + y = 7
x - y = -1
```
1. Solve each for y mentally (or type implicit if allowed): `y1=-2x+7`, `y2=x+1`.
2. Type both → click intersection → (2,3) → x=2, y=3.
3. Verify: plug into original (fast) or table.

No-solution = parallel (same slope, different intercept). Infinite = same line (overlaps fully).

## Sliders for Word Problems
`total = base + rate×n` → `y=50+25x` slider on rate. Drag to see break-even. Faster than table for “when equal?” Qs.

## Table-Test Choices (no solving)
`+` → Table → x column enter A-D values → y auto-fills for your equation → match given y. Best for “which value satisfies?” Qs.

## Traps
- Solving for `2x` not `x` — read ask, multiply after intersection.
- Fractions: type `1/2` not `1 / 2 spaced wrong`. Use parentheses `(2x+3)/4`.
- Zoom hides intersection — zoom out or settings → square.
