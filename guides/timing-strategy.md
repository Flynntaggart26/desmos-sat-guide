# Timing Strategy — 60-Second Rule

## The Rule
Start timer mentally: if setup + algebra path >60s, switch to Desmos. If Desmos >60s (simple one-step), switch to hand.

| Q type | First try | Switch if |
|--------|-----------|-----------|
| System 2x2 | Desmos intersection | Lines won’t isolate in 20s |
| Quadratic roots/vertex | Desmos graph | Factoring obvious in <15s → hand |
| Equivalent | Plug x=2 | 2+ choices survive → graph overlap |
| Inequality | Graph + test (0,0) | Simple `x+3>5` → hand |
| Circle | Type equation, read center/r | Completing square obvious → hand |
| Stats | Table + mean/median | Definition Q (no calc) → hand |

## Flagging (adaptive survival)
RW >90s or Math >2 min → guess, flag in Bluebook, move. Review flagged only with 3+ min left. One early stuck Q can lock you out of hard Module 2.

## Practice Protocol
Redo 5 old misses both ways, time each with phone. Log faster in `templates/desmos-log.csv`. After 2 weeks you’ll know in 5s which way.
